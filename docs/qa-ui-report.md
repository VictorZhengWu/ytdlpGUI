## 三、判读项裁定（全部非阻塞）

| 项 | 裁定 | 依据 |
|---|---|---|
| UI-08 资源加载断言 | **断言方法缺陷，非产品缺陷** | 磁盘缓存命中时 `transferSize=0` 属正常；资源实际 HTTP 200。建议断言改用 `responseStatus===200` 或 `decodedBodySize>0` |
| UI-16 终态=error | **预期内** | 任务含 404 URL，用例预期为「60 秒内到终态、无假死」，error 即终态；该用例同时暴露 D3（已修） |
| UI-69 spd 未捕获值 | **环境因素，非缺陷** | 2K 限速 + 快速取消导致观测窗口过短；UI-61/62/63 已覆盖进度链路 |
| UI-76 首查失败、复查通过 | **加载时序，非缺陷** | 历史列表异步加载中的瞬态 |
| UI-81 检出中文=语言下拉原生语言名 | **合理保留（i18n 惯例）** | 语言选择器显示 endonym（中文/日本語/한국어）是标准做法，属有意设计 |
| UI-88「字幕」同形 | **方法假阳性，非缺陷** | quick.js 的 ja 正译本就是「字幕」（汉字同形词），zh 快照比对法对此类词天然误报；en/ja/ko 其余标签全部通过佐证无回落 |
| already-downloaded 路径行为空（D5 备注） | **接受为已知限制（P3）** | yt-dlp 实际输出为 `[download] {path} has already been downloaded`（路径前置、无冒号，见 YoutubeDL.py L1180），`DESTINATION_RE` 的 `Already downloaded:` 分支永不命中；该场景文件本已存在于本地、信息价值低。改进建议：正则增加分支 `\[download\]\s+(.+?)\s+has already been downloaded`（L1182 的无路径变体同理不命中） |

## 四、改进建议（非缺陷，按价值排序）

1. **D5 正则补充**（上表）：一行改进覆盖 already-downloaded 场景的路径显示。
2. **发布前 UI 冒烟清单固化**：把 UI-01/06/07（boot）、UI-26（tri≥40，D1 回归哨兵）、UI-81 式 CJK 扫描（en）三项列为人工快检项，或纳入后续 e2e 自动化；D1 这类「重建后状态丢失」最易在改语言相关代码时回归。
3. **断言工具沉淀**：本轮 `qaCmdCmp`（预览 vs 后端 command）与 zh 快照比对法可复用；快照法需注意同形词假阳性（UI-88 教训）。
4. D1 附注：`renderedGroups` 若未来引入跨节互斥组需改为整面板单 Set（当前无影响）。
